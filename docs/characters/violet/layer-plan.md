# Violet · 拆层原画清单 v0.1

这是待制作清单，不代表已经完成自动拆层。
所有部件在同一画布坐标中对齐。遮挡后的内容需要完整补画。

| 图层组 | 需要独立制作的内容 | 检查重点 |
| --- | --- | --- |
| 后发 | 后发底、左右后发束、蓝色内层 | 头部转动后不露空白。 |
| 脸部 | 完整脸底、耳朵、鼻、脸部阴影 | 完整补画刘海和围巾遮住的区域。 |
| 眉毛 | 左右眉毛 | 能独立表达困倦、惊讶、委屈。 |
| 眼睛 | 左右眼白、虹膜、瞳孔、高光、上下眼皮、睫毛 | 即使遮眼，也补画完整眼睛。 |
| 金点与耳饰 | 眼下标记、耳饰 | 跟随对应脸部与耳朵。 |
| 嘴 | 上下唇线、口腔、舌头、必要的牙齿 | 张闭嘴时不出现断裂或空洞。 |
| 前发 | 刘海大束、左右侧发、呆毛、发丝高光 | 遮眼刘海与脸独立。 |
| 颈部 | 完整颈部与阴影 | 围巾降低和转头时不露空白。 |
| 衣服 | 躯干、左右袖、袖口、下摆、拉链和金色拉头 | 不把整件衣服合成唯一运动层。 |
| 手 | 露出的左右手与手指 | 中立姿势下自然，不强行增加复杂动作。 |
| 腿与鞋袜 | 左右腿、袜子、鞋 | 围巾挪动后腿部轮廓完整。 |
| 围巾颈圈 | 前面、左右侧面、后面、褶皱阴影 | 遮挡嘴的状态可独立调整。 |
| 围巾长尾 | 前尾、后尾、沿长度分段的结构、流苏、补丁 | 使用连续网格和局部形变，不只旋转整张图。 |
| 金色点缀 | 跟随对应布料的纹理 | 不在变形时漂离衣服或围巾。 |

## 第一版绑定验收目标

- 自然呼吸与轻微身体摆动。
- 头部左右、上下与倾斜。
- 眨眼、视线变化与困倦眼神。
- 说话口型。
- 刘海、呆毛和围巾的小幅物理摆动。
- 平静、困倦、害羞三个基础表情。
- 围巾默认位置与露嘴位置的表现方案待用户确认。
