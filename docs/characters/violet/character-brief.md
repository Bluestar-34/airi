# Violet · 形象制作说明 v0.1

## 来源

形象来自用户提供的 Violet 素材目录，共 7 张 PNG。
原图保持不变。新增文件放在 `live2d/` 下。

## 参考优先级

1. `ChatGPT Image 2026年7月23日 20_40_14.png`：正面全身轮廓、衣服长度和鞋袜。
2. `Melancholic Anime Portrait with Gold Beauty Mark.png`：面部、眼神、发型、金点和耳饰细节。
3. `ChatGPT Image 2026年7月23日 21_48_53.png`：正侧背三视图。
4. `ChatGPT Image 2026年7月23日 20_52_34.png`：表情、围巾情绪与动作设定。
5. 其余三张：场景和动作气氛参考，不直接作为中立建模姿势。

## 需要保留的特征

- 黑蓝色蓬松短发，蓝色内层发丝和弯曲呆毛。
- 正面画面左侧的眼睛被长刘海遮住。
- 可见眼睛为偏困倦的琥珀金色眼睛，眼下有金色点状标记。
- 苍白肤色，安静、内敛、困倦的气质。
- 宽大的黑色长袖衣服、小型金色拉链头。
- 深蓝色超长围巾，稀疏金色斑点、小块金色补丁。
- 黑袜和厚底黑鞋。

名字 Violet 不意味着改用紫发、紫瞳或紫色服装。
不同参考图的比例与细节略有差别，不能直接混成一套已经定稿的分层原画。

## 建模参考的技术调整

- 使用正面、直立、无歪头的中立姿势。
- 手臂与身体之间留出轮廓间隙。
- 围巾长尾避免横穿双腿，便于独立绑定。
- 参考版本暂时把围巾降至下巴以下，以显示嘴和下颌。
- 降低围巾是待验收的建模处理，不表示覆盖原设定。
- 正式模型需要补画遮住的眼睛、完整脸部、嘴和颈部。

## 暂缓范围

- 黑猫先作为后续可选配件，不放入首版基础人物绑定。
- 大幅漂浮围巾、悬挂姿势和广播场景留作后续动作或场景。
- 年龄、身高、声音、性格背景未由用户明确确认，不作额外设定。
